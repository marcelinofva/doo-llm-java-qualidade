# S30 - MIS (repositorio digital): ingestao em lote de teses
Fonte: https://doi.org/10.17632/7zbk8zsd8y.2 (arquivo g16-mis.txt, linhas 23, 24, 29, 32, 34, 37, 54, 55)   Licenca: CC BY 4.0   Recorte: ingestao em lote de teses

US1: As a DigitalRecords Archivist, I want to have a method to batch ingest ETDs we receive from ProQuest.
US2: As a DigitalRecords Archivist, I want to have the batch ingest tool to recognize and set embargoes, permissions for embargoed items should be allow everyone to view metadata, and collection curator and repository administrators to download the files.
US3: As a DigitalRecords Archivist, I want to expose the descriptive record for each ETD item for re-use external to Fedora.
US4: As a collection curator, I want to have a tool to perform author authority control.
US5: As a repoadmin, I want to expose repository contents via OAI-PMH.
US6: As a batch submitter, I want to provide my data and metadata in a simple, documented format to the repository staff for ingest.
US7: As a depositor, I want to get feedback post-ingest alerting me if files I submitted do not conform to their format specifications, if they are not valid, or if they are not wellformed.
US8: As a batch submitter, I want to access documentation describing the folder ingest process.
