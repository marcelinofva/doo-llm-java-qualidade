# S24 - verificação manual

## Histórias

- US1: As an OlderPerson, I want to use ALFRED to contact help in case of an emergency.
- US2: As a MedicalCaregiver, I want to use video calls in case of emergency.
- US3: As an OlderPerson, I want to have ALFRED contact the nearest caregiver when I ask ALFRED for urgent help.
- US4: As an OlderPerson, I want to receive a message when my home care nurse is on her way.
- US5: As an OlderPerson, I want to receive a medicine reminder from ALFRED.
- US6: As an OlderPerson, I want to be able to see whether I already have taken my pills, so that I can avoid an overdose.
- US7: As a MedicalCaregiver, I want to be able to see if the patient has taken her medicine.
- US8: As an OlderPerson, I want to have ALFRED to detect falls and send an emergency to a specific contact.
