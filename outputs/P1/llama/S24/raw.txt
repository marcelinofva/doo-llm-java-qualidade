**Phase 1 - DESIGN**

```xml
<design>
  1. Domain entities (classes):
    * OlderPerson
    * MedicalCaregiver
    * Caregiver
    * HomeCareNurse
    * Medication
    * Emergency
    * FallDetector

  2. Single responsibility of each class:
    * OlderPerson: represents an older person, stores their information and interactions with ALFRED
    * MedicalCaregiver: represents a medical caregiver, stores their information and interactions with ALFRED
    * Caregiver: represents a caregiver, stores their information and interactions with ALFRED
    * HomeCareNurse: represents a home care nurse, stores their information and interactions with ALFRED
    * Medication: represents a medication, stores its information and interactions with ALFRED
    * Emergency: represents an emergency, stores its information and interactions with ALFRED
    * FallDetector: detects falls and sends emergencies to specific contacts

  3. Relationships (association, composition, inheritance):
    * OlderPerson has a one-to-many relationship with Medication (an older person can have multiple medications)
    * OlderPerson has a one-to-one relationship with Caregiver (an older person has one caregiver)
    * MedicalCaregiver has a one-to-many relationship with OlderPerson (a medical caregiver can care for multiple older persons)
    * HomeCareNurse has a one-to-many relationship with OlderPerson (a home care nurse can care for multiple older persons)
    * Medication has a one-to-one relationship with Emergency (a medication can be associated with one emergency)
    * FallDetector has a one-to-one relationship with Emergency (a fall detector can send emergencies to specific contacts)

  4. Public methods of each class:
    * OlderPerson: getMedications(), getCaregiver(), requestUrgentHelp(), receiveMessage()
    * MedicalCaregiver: getOlderPersons(), getVideoCall()
    * Caregiver: getOlderPerson(), getContactInformation()
    * HomeCareNurse: getOlderPerson(), getContactInformation()
    * Medication: getEmergency(), getDosage()
    * Emergency: getMedication(), getContactInformation()
    * FallDetector: detectFall(), sendEmergency()
</design>
```

### Main.java
```java
// File: Main.java

public class Main {
    public static void main(String[] args) {
        OlderPerson olderPerson = new OlderPerson("John");
        MedicalCaregiver medicalCaregiver = new MedicalCaregiver("Jane");
        Caregiver caregiver = new Caregiver("Bob");
        HomeCareNurse homeCareNurse = new HomeCareNurse("Alice");
        Medication medication = new Medication("Painkiller");
        Emergency emergency = new Emergency();
        FallDetector fallDetector = new FallDetector();

        olderPerson.addMedication(medication);
        olderPerson.setCaregiver(caregiver);
        olderPerson.setHomeCareNurse(homeCareNurse);

        medicalCaregiver.addOlderPerson(olderPerson);

        caregiver.setContactInformation("123-456-7890");
        homeCareNurse.setContactInformation("987-654-3210");

        medication.setEmergency(emergency);
        emergency.setMedication(medication);
        emergency.setContactInformation("555-123-4567");

        fallDetector.detectFall();
        fallDetector.sendEmergency();

        olderPerson.requestUrgentHelp();
        olderPerson.receiveMessage();

        medicalCaregiver.getVideoCall();
    }
}
```
