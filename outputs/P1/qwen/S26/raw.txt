<design>
1) Domain Entities (Classes):
   - User
   - Role
   - Repository
   - AuthenticationMethod
   - Record

2) Single Responsibility:
   - User: Manages user details and roles.
   - Role: Manages different roles and their permissions.
   - Repository: Manages records within a repository.
   - AuthenticationMethod: Manages different authentication methods.
   - Record: Manages records within a repository.

3) Relationships:
   - User has many Roles.
   - Role has many Users.
   - Repository has many Records.
   - User has one AuthenticationMethod.
   - Record belongs to one Repository.

4) Public Methods:
   - User: resetPassword(), createUser(), authenticate().
   - Role: assignRole(), removeRole().
   - Repository: createRecord(), updateRecord(), deleteRecord().
   - AuthenticationMethod: authenticateUser().
   - Record: viewRecord(), updateRecord().
</design>

```java
public class Main {
    public static void main(String[] args) {
        User admin = new User("admin", "admin123", new LocalAuthentication());
        Role repositoryManager = new Role("Repository Manager", Arrays.asList("create", "update", "delete"));
        Repository repository = new Repository("Main Repository");

        admin.assignRole(repositoryManager);
        repository.createRecord(new Record("1", "Initial Record"));

        User readOnlyUser = new User("readonly", "readonly123", new LocalAuthentication());
        readOnlyUser.assignRole(new Role("ReadOnly", Arrays.asList("view")));

        User basicUser = new User("basic", "basic123", new LocalAuthentication());
        basicUser.assignRole(new Role("Basic Data Entry", Arrays.asList("create", "update")));

        admin.resetPassword("newAdminPassword");
        readOnlyUser.authenticate();
        basicUser.authenticate();
    }
}
```
