# S26 - ArchivesSpace: usuarios, papeis e autenticacao
Fonte: https://doi.org/10.17632/7zbk8zsd8y.2 (arquivo g23-archivesspace.txt, linhas 2, 25, 49, 6, 47, 48, 46, 54)   Licenca: CC BY 4.0   Recorte: usuarios, papeis e autenticacao

US1: As an Application Administrator, I want to be able to reset a User's password for them.
US2: As an Administrator, I want to create a new User account for someone else.
US3: As an System Administrator, I want to declare that a user is has the Repository Manager role for a given Repository.
US4: As a User , I want to authenticate using LDAP.
US5: As a Repository Manager , I want to create, update and delete any records in my repository.
US6: As a ReadOnly user , I want to view archival descriptions in my repository.
US7: As a Basic Data Entry user , I want to create and update basic archival description information.
US8: As a User, I want to authenticate locally.
