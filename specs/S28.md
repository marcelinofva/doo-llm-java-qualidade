US1: As an Archivist, I want to associate a standard identifier string with a Subject heading.
US2: As an Archivist, I want to import Agent information from EAC-CPF records.
US3: As an Archivist, I want to export agent records as EAC-CPF.

US7: As an Archivist, I want to create and edit Agent records.
