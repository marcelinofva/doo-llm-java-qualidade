# S04 - verificação manual

## Histórias

- US1: As a Publisher, I want to import my data package into the registry, so that my data has a permanent online home to access.
- US2: As a Publisher, I want to use a publish command to update a data package that is already in the registry, so that it appears there.
- US3: As a Publisher, I want to unpublish a data package, so that it is no longer visible to anyone.
- US4: As a Publisher, I want to permanently delete a data package, so that that it no longer takes up storage space.
- US5: As a Publisher, I want to be able to restore the deleted data package via cli, so that that it is back visible and available to view, download.
- US6: As a Publisher, I want to undelete the deleted data packages, so that that the deleted data packages is now visible again.
- US7: As a Publisher, I want to validate the data I am about to publish to the registry, so that that I publish good data and know that I am doing.
- US8: As a Publisher, I want to data to be validated when I publish it, so that that I know immediately if I have accidentally broken my data or have bugs and can take action to correct.
