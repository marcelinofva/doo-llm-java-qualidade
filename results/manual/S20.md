# S20 - verificação manual

## Histórias

- US1: As an archivist, I want to mark individual files as restricted, so that they don't get shared by mistake.
- US2: As an archivist, I want to mark groups of files as restricted, so that they don't get shared by mistake.
- US3: As an archivist, I want to add restriction end date information to files, so that I can share files when they become open.
- US4: As an archivist, I want to add detailed restrictions to groups of files, so that I know if and how they can be shared.
- US5: As an archivist, I want to restrict access to some files by IP address, so that I can give reading room access only to certain digital files.
- US6: As an archivist, I want to restrict access to certain files by user, so that I can allow donor representatives to see certain files.
- US7: As an archivist, I want to redact information in digital files for a period of time, so that I can provide access to non-sensitive portions of a record.
- US8: As an archivist, I want to upload groups of files, so that I can save time.
