<design>
1) Domain Entities (Classes):
   - Collection
   - Item
   - User
   - Repository

2) Single Responsibility of Each Class:
   - Collection: Manages collection details and items.
   - Item: Represents a single item in a collection.
   - User: Manages user details and permissions.
   - Repository: Manages collections and items.

3) Relationships:
   - Collection has many Items (composition).
   - User has many Collections (composition).
   - Repository has many Collections (composition).

4) Public Methods:
   - Collection: createCollection, renameCollection, moveCollection, applyBranding, sortItems
   - Item: addItem, removeItem, updateItem
   - User: createUser, deleteUser, assignCollection
   - Repository: createRepository, moveCollection, renameCollection
</design>

// File: Repository.java
```java
public class Repository {
    private List<Collection> collections;

    public Repository() {
        this.collections = new ArrayList<>();
    }

    public void createCollection(Collection collection) {
        collections.add(collection);
    }

    public void moveCollection(Collection collection, String newLocation) {
        collection.move(newLocation);
    }

    public void renameCollection(Collection collection, String newName) {
        collection.rename(newName);
    }
}
```

// File: Main.java
```java
public class Main {
    public static void main(String[] args) {
        Repository repository = new Repository();
        User user = new User("facultyMember");

        Collection collection = new Collection("My Collection");
        collection.applyBranding("Faculty Branding");
        collection.sortItems();

        Item item1 = new Item("Item 1", "Description 1", "Author 1");
        Item item2 = new Item("Item 2", "Description 2", "Author 2");
        collection.addItem(item1);
        collection.addItem(item2);

        user.assignCollection(collection);
        repository.createCollection(collection);

        // Simulate moving and renaming collection
        repository.moveCollection(collection, "New Location");
        repository.renameCollection(collection, "Renamed Collection");
    }
}
```
