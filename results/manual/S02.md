# S02 - verificação manual

## Histórias

- US1: As a camp administrator, I want to be able to add campers, so that I can keep track of each individual camper.
- US2: As a camp administrator, I want to be able to add parents, so that they can enroll their kids at camp.
- US3: As a parent, I want to be able to enroll my children, so that they can be admitted to camp.
- US4: As a camp administrator, I want to be able to create groups and add campers to the groups, so that I can easily organize the campers.
- US5: As a camp administrator, I want to be able to schedule tasks/activities for a specific camp group, so that I can track each groups daily/weekly and monthly activities.
- US6: As a camp administrator, I want to be quickly log attendance everyday, so that I can track which kids are coming in.
- US7: As a camp counselor, I want to be able to take attendance of my assigned kids, so that I can make ensure everybody is accounted for.
- US8: As a camp administrator, I want to be able to assign different positions to the staff members, so that it is possible to organize activities in terms of responsibilities.
