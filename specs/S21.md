# S21 - CULRepo (repositorio universitario): colecoes do repositorio
Fonte: https://doi.org/10.17632/7zbk8zsd8y.2 (arquivo g27-culrepo.txt, linhas 30, 17, 96, 97, 109, 92, 37, 38)   Licenca: CC BY 4.0   Recorte: colecoes do repositorio

US1: As a Cornell faculty member, I want to create a collection for my documents, or my organization's documents, and apply some distinctive branding to that collection, so that I can promote my work, or that of my organization.
US2: As a Cornell faculty member, I want to have some control over how items within my collection sort in collection contents lists, so that I can control how my work is presented.
US3: As a repository support team member, I want to move a collection, so that I can fulfill the collection owner's request.
US4: As a repository support team member, I want to rename a collection, so that I can fulfill the collection owner's request.
US5: As a library staff member, I want to create a collection, sometimes with custom metadata fields, so that I can house digital material for wider distribution.
US6: As a faculty member, I want to recommend a digital collection be built in the repository, so that I can assist in my research.
US7: As a researcher, I want to receive updates when new works are published in a given collection or by a given author, so that I can discover more of their work.
US8: As a researcher, I want to search within a repository or collection in an effective manner, including searching within subsets of a given collection, so that I can facilitate my use of the collection.
