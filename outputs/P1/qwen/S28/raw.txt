<design>
1) Domain Entities (Classes):
   - Agent
   - Subject
   - Source
   - Accession
   - Resource
   - ResourceComponent

2) Single Responsibility of Each Class:
   - Agent: Manages agent information and relationships.
   - Subject: Manages subject information and relationships.
   - Source: Manages source information and relationships.
   - Accession: Manages accession information and relationships.
   - Resource: Manages resource information and relationships.
   - ResourceComponent: Manages resource component information and relationships.

3) Relationships:
   - Agent can have multiple Subjects.
   - Agent can have multiple Sources.
   - Agent can be associated with multiple Accessions.
   - Agent can be associated with multiple Resources.
   - Agent can be associated with multiple Resource Components.
   - Subject can be associated with multiple Agents.
   - Source can be associated with multiple Agents.
   - Accession can be associated with multiple Agents.
   - Resource can be associated with multiple Agents.
   - Resource Component can be associated with multiple Agents.

4) Public Methods:
   - Agent: addSubject, addSource, addAccession, addResource, addResourceComponent
   - Subject: addAgent
   - Source: addAgent
   - Accession: addAgent
   - Resource: addAgent
   - ResourceComponent: addAgent
</design>

// File: Agent.java
```java
public class Agent {
    private String identifier;
    private List<Subject> subjects = new ArrayList<>();
    private List<Source> sources = new ArrayList<>();
    private List<Accession> accessions = new ArrayList<>();
    private List<Resource> resources = new ArrayList<>();
    private List<ResourceComponent> resourceComponents = new ArrayList<>();

    public void addSubject(Subject subject) {
        subjects.add(subject);
    }

    public void addSource(Source source) {
        sources.add(source);
    }

    public void addAccession(Accession accession) {
        accessions.add(accession);
    }

    public void addResource(Resource resource) {
        resources.add(resource);
    }

    public void addResourceComponent(ResourceComponent resourceComponent) {
        resourceComponents.add(resourceComponent);
    }

    // Getters and setters
}
```

// File: Main.java
```java
public class Main {
    public static void main(String[] args) {
        Agent agent = new Agent();
        agent.setIdentifier("A123");

        Subject subject = new Subject();
        subject.setIdentifier("S456");
        subject.addAgent(agent);

        Source source = new Source();
        source.setIdentifier("S789");
        source.addAgent(agent);

        Accession accession = new Accession();
        accession.setIdentifier("AC101");
        accession.addAgent(agent);

        Resource resource = new Resource();
        resource.setIdentifier("R202");
        resource.addAgent(agent);

        ResourceComponent resourceComponent = new ResourceComponent();
        resourceComponent.setIdentifier("RC303");
        resourceComponent.addAgent(agent);

        agent.addSubject(subject);
        agent.addSource(source);
        agent.addAccession(accession);
        agent.addResource(resource);
        agent.addResourceComponent(resourceComponent);

        System.out.println("Agent: " + agent.getIdentifier());
        System.out.println("Subjects: " + agent.getSubjects());
        System.out.println("Sources: " + agent.getSources());
        System.out.println("Accessions: " + agent.getAccessions());
        System.out.println("Resources: " + agent.getResources());
        System.out.println("Resource Components: " + agent.getResourceComponents());
    }
}
```
