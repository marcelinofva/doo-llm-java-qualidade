# S13 - verificação manual

## Histórias

- US1: As a Practitioner, I want to include additional details about me in my profile page, so that I can showcase my experience.
- US2: As a Trainer, I want to include additional details in my profile page about me, so that others can learn about me and decide if I am the right trainer for them.
- US3: As a trainer, I want to list my upcoming classes in my profile and include a link to a detailed page about each, so that prospective attendees can find my courses.
- US4: As a site member, I want to view the profiles of other members, so that I can find others I might want to connect with.
- US5: As a site member, I want to search for profiles based on a few fields, so that I can find others I might want to connect with.
- US6: As a site member, I want to mark my profile as private in which case only my name will appear, so that no one can learn things about me I don't want shared.
- US7: As a site member, I want to mark my email address as private even if the rest of my profile is not, so that no one can contact me.
- US8: As a site administrator, I want to edit any site member profile, so that I can correct problems for members.
