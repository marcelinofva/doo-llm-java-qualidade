# S03 - verificação manual

## Histórias

- US1: As a user, I want to be able to create an acocunt, so that I can create my own profile.
- US2: As a user, I want to be able to enter my zip code and get a list of nearby recycling facilities, so that I can determine which ones I should consider.
- US3: As a user, I want to be able to get the hours of each recycling facility, so that I can arrange drop-offs on my off days or during after-work hours.
- US4: As a user, I want to be able to select different types of recyclable waste, so I have and get a list of facilities that accept each type and their opening hours, so that I can find an optimal route and schedule.
- US5: As a user, I want to add donation centers as favorites on my profile, so that I can view them later.
- US6: As a user, I want to be able to view the safe disposal events currently being organised around my area.
- US7: As a user, I want to be able to give my email ID, so that I can receive notifications for new events as they are posted.
- US8: As an admin, I want to be able to add or remove recycling facilities' information, so that users get the most recent information.
