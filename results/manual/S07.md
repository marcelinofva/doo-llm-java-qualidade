# S07 - verificação manual

## Histórias

- US1: As a collection curator, I want to lift an embargo for an object in a simple way.
- US2: As a collection curator, I want to allow some collections the option of setting an embargo date at deposit.
- US3: As a collection curator, I want to have item metadata to be discoverable while the item is under embargo.
- US4: As a DigitalRecords Archivist, I want to have the repository to lift embargoes on the release date and set the access controls to the configuration set on item on that date.
- US5: As a visitor, I want to see the embargo status and release date clearly displayed and perhaps highlighted in some way.
- US6: As a DigitalRecords Archivist, I want to edit the length of embargoes.
- US7: As a DigitalRecords Archivist, I want to grant embargo privileges to other repository administrators.
- US8: As a DigitalRecords Archivist, I want to view and download summary embargo metadata for all ETDs in the repository.
