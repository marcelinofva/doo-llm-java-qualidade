**Phase 1 - DESIGN**

```xml
<design>
  1. Domain entities:
    - User
    - RecyclingFacility
    - DonationCenter
    - Event
    - Admin

  2. Single responsibility of each class:
    - User: manage user profile, favorites, and notifications
    - RecyclingFacility: store and manage recycling facility information
    - DonationCenter: store and manage donation center information
    - Event: store and manage event information
    - Admin: manage recycling facility and donation center information

  3. Relationships:
    - User has many RecyclingFacility (favorites)
    - User has many DonationCenter (favorites)
    - RecyclingFacility has many Event (associated events)
    - Admin has many RecyclingFacility (managed facilities)
    - Admin has many DonationCenter (managed centers)

  4. Public methods of each class:
    - User: addFavorite(RecyclingFacility), addFavorite(DonationCenter), getFavorites(), subscribeToNotifications()
    - RecyclingFacility: getHours(), getAcceptedWasteTypes(), getOpeningHours()
    - DonationCenter: getDonationTypes(), getOpeningHours()
    - Event: getEventDetails(), getEventLocation()
    - Admin: addFacility(RecyclingFacility), removeFacility(RecyclingFacility), addCenter(DonationCenter), removeCenter(DonationCenter)
</design>
```

public class Admin {
    private List<RecyclingFacility> managedFacilities;
    private List<DonationCenter> managedCenters;

    public Admin() {
        this.managedFacilities = new ArrayList<>();
        this.managedCenters = new ArrayList<>();
    }

    public void addFacility(RecyclingFacility facility) {
        managedFacilities.add(facility);
    }

    public void removeFacility(RecyclingFacility facility) {
        managedFacilities.remove(facility);
    }

    public void addCenter(DonationCenter center) {
        managedCenters.add(center);
    }

    public void removeCenter(DonationCenter center) {
        managedCenters.remove(center);
    }

    public List<RecyclingFacility> getManagedFacilities() {
        return managedFacilities;
    }

    public List<DonationCenter> getManagedCenters() {
        return managedCenters;
    }
}

// File: Main.java

public class Main {
    public static void main(String[] args) {
        User user = new User("1", "John Doe");
        RecyclingFacility facility = new RecyclingFacility("1", "Facility 1", "123 Main St");
        DonationCenter center = new DonationCenter("1", "Center 1", "456 Elm St");
        Event event = new Event("1", "Event 1", "789 Oak St");

        user.addFavorite(facility);
        user.addFavorite(center);
        facility.addAcceptedWasteType("Paper");
        center.setDonationTypes("Clothing, Shoes");

        System.out.println("User Favorites:");
        for (RecyclingFacility facility : user.getFavorites()) {
            System.out.println(facility.getName());
        }

        System.out.println("Donation Center Favorites:");
        for (DonationCenter center : user.getFavoritesDonation()) {
            System.out.println(center.getName());
        }

        System.out.println("Facility Hours:");
        System.out.println(facility.getHours());

        System.out.println("Event Details:");
        System.out.println(event.getEventDetails());
    }
}
